# Source Code

## Recommended Baseline

The proposed machine-learning baseline for this project is:

**TF-IDF + Logistic Regression**

TF-IDF converts customer-support ticket text into numerical features, while Logistic Regression predicts the ticket priority.

## Planned Workflow

1. Load the support-ticket dataset.
2. Clean and preprocess the text.
3. Split the dataset into training and testing sets.
4. Convert text into TF-IDF features.
5. Train a Logistic Regression classifier.
6. Predict High, Medium, and Low priority.
7. Evaluate accuracy, precision, recall, F1-score, and confusion matrix.

The model implementation can be added here after expanding the labeled dataset and establishing a suitable training and evaluation pipeline.
